# Singularity Note

Singularity Note 是面向学习与知识管理场景的智能工作台，帮助用户统一整理课程资料、开展基于材料的对话，并把重要内容沉淀为持续可复习的知识。

## 产品能力

- 统一管理文档、图片、音频和视频等学习资料。
- 围绕个人资料进行上下文连贯的问答与探索。
- 在回答中关联原始依据，便于核对和回看。
- 将重要结论整理为笔记和复习卡片。
- 以独立学习空间组织资料、对话和学习进度。
- 提供 Web 与移动端一致的学习体验。
